## About

I'm **Ethan**, a 20-year-old software engineering student in the **MAALSI** program at **CESI École d'ingénieurs** — after completing a Bachelor **CDA** (*Concepteur Développeur d'Applications*). I'm currently a **work-study developer at Orange Business** (Eysines, Bordeaux), based in Talence, Gironde, France.

I build **full-stack web and mobile applications** end to end — from data modeling and API design through to polished, responsive interfaces and production deployment. I approach features with a **product-engineering mindset**: I care as much about maintainability, testing and CI/CD as I do about shipping something people actually enjoy using.

Previously, I was a work-study developer at **Capgemini Engineering** on the **SNG** project for **SNCF Réseau**, working across an **Angular / NgRx** front end and a **Java Spring Boot** back end.

> **Open to:** full-stack / web developer opportunities.
